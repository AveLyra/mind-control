One important distinction: TMR itself has already been studied, including with auditory cues and memory tests. Your project’s case needs to rest on the specific gap you want to test—potentially whether carefully calibrated, low-intensity cues can be delivered without disrupting sleep, and what next-day memory and cue-awareness measures show. TITLE
Can Low-Intensity Sleep Cues Reactivate Newly Learned Memories?

ABSTRACT
Targeted memory reactivation (TMR) pairs a sound with learning while a person is awake, then replays that sound during sleep to cue the associated memory. This proposed pilot will test whether a low-intensity auditory TMR protocol can be delivered during monitored sleep without unacceptable disruption, and whether it yields usable next-day memory measures. Participants will learn material paired with distinct sounds; a selected set of sounds will be replayed during a sleep stage defined in advance with the participating sleep laboratory. The next day, memory for cued and comparison items will be tested. The pilot’s primary purpose is to assess cue-delivery reliability, sleep disruption, test completion, and other measures needed to plan a larger study. Any difference in memory performance will be treated as preliminary, not proof that the method improves memory. If predefined criteria are met, the results will guide a preregistered, adequately powered follow-up study.

CONTEXT
In TMR, cues associated with information learned while awake are replayed during sleep, and later memory is compared for cued and comparison material. Human studies have reported TMR effects, but outcomes can depend on the learning task, cue, sleep stage, and sound intensity. [Review of TMR research](https://doi.org/10.1111/nyas.13855) This project will focus on a low-intensity sound-cueing protocol and the practical conditions needed to measure its effects reliably.

SIGNIFICANCE
A memory study can be hard to interpret if cues are mistimed, disturb sleep, or are followed by incomplete testing. This pilot will measure those risks and assess whether next-day memory testing and cue-awareness checks work as planned. Its results will help the team decide whether to revise the method, stop, or proceed to a larger study designed to test whether sleep cues change memory performance.

GOALS
We will pair selected learning items with sounds, replay a subset of those sounds during a sleep stage defined in advance with the lab, and compare next-day memory for cued and comparison items. We will assess cue-delivery success, sleep disruption, completion of the memory test, and awareness of sounds. Before data collection, we will define criteria for proceeding, revising, or stopping. Any memory difference observed in this pilot will be considered preliminary; the main deliverable is a documented feasibility assessment and a justified plan for the next study.
