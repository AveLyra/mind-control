# Sleep/Acoustic Reference Campaign

This campaign tests a narrow proposition: whether a predefined latent physiology
event is followed by an independently recorded acoustic onset more often than
matched within-night control windows after registered movement, respiration,
data-quality, and negative-control checks.

It does not test source, mechanism, adaptation, attribution, or intent. Those
claims appear in the hypothesis graph so the engine can prevent inferential
promotion and select later discriminating experiments.

The committed protocol is a development reference. A real confirmatory study
must create a new write-once registration with an external timestamp anchor,
power or precision justification, reviewed safety limits, calibrated adapters,
and a newly computed analysis hash.
